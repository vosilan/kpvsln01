# Визуализатор графа зависимостей пакетов

**Вариант:** 19  
**Тема:** Разработка инструмента визуализации графа зависимостей для менеджера пакетов

## Что реализовано

CLI-инструмент для анализа и визуализации зависимостей пакетов Ubuntu/Debian.

### Основные функции:
- Анализ прямых и транзитивных зависимостей
- Обход графа BFS с ограничением глубины
- Обнаружение циклических зависимостей  
- Топологическая сортировка (порядок установки)
- Визуализация: ASCII-дерево и Graphviz
- Сравнение с реальным apt

### Библиотеки:
- `argparse` - парсинг аргументов командной строки
- `urllib.request` - загрузка данных из репозиториев
- `re` - парсинг файлов Packages
- `collections` - работа с графами
- `subprocess` - интеграция с apt

### Этапы разработки:
1. Базовый CLI с валидацией параметров
2. Парсинг зависимостей из репозиториев Ubuntu
3. Построение графа BFS с обработкой циклов
4. Топологическая сортировка и сравнение с apt
5. Визуализация через Graphviz и ASCII-дерево

**Язык:** Python 3  
**Тестирование:** Локальные тест-кейсы + реальные пакеты Ubuntu
